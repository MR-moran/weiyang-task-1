##组队名片生成器

一个面向黑客松现场的组队名片生成工具。填写技能、兴趣和联系方式，一键生成可分享的组队卡片，可供黑客松参赛成员使用。

##运行方式
纯前端实现，只需用浏览器打开就能使用。

## 技术栈

- HTML5 -- 页面结构
- CSS3 -- 布局与样式
- JavaScript -- 交互逻辑与状态管理
- html2canvas -- 将名片DOM 导出为 PNG
- Clipborad API -- 复制名片文案
- FileReader API == 读取本地上传的头像图片

##核心功能
- 填写昵称，一句话介绍
- 点选技能标签（预设10个，最多可选4个）
- 点选兴趣标签（预设7个，最多可选4个）
- 头像：可选8个预设emoji或上传本地图片
- 可选6中名片主题色（紫，蓝，橙，绿，黑，灰）
- 右侧名片可实时预览
- 可一键下载PNG格式名片
- 可一键复制纯文本文案
- 可一键重置所有输入

##边界与风险
- 复制出来的文案缺少必要的文字说明，可能出现理解问题。  解决方法：在JS中的"复制文案"中添加相应文字说明
- 可能出现头像图片过大导致的导出慢或失败问题。  解决方法：限制了可上传图片最大为2MB。
- 主题色选择中有一个灰白主题，可能导致文字难以阅读。  解决方法：可添加灰白主题下文字反色（未实现）

##换作我怎么做
- 优先级最高：给灰白主题添加文字反色  方法：给每个主题设置独立的文字颜色，其他主题用白色，灰白主题用黑色。  可能付出的代价：需要更改CSS和JavaScript部分代码，可能导致网页运行出现问题。
- 优先级较高：网页可储存数据  方法：利用localStorage储存网页数据。  可能付出的代价：多个标签页同时存在时可能冲突。
- 优先级较低：头像自动压缩和裁剪 方法：上传图片后利用canvas压缩，然后居中裁剪，最后再转为base64。  可能付出的代价：需要写入额外的函数，交互时需要loading提示
